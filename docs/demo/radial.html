Chapter 2

Learning a distance

Use distance as a score, then learn which directions should count most.

Derive the shape of an equal-score contour

A radial head scores a key by its squared distance from the query. The head learns positive coordinate weights mi and bandwidth σ.

s(q, k) = −∑i mi(qi − ki)2 / (2σ2)

Set the score to −½ and put the query at the origin. In two dimensions the contour satisfies mxx2 + myy2 = σ2. On the horizontal axis, y = 0, so the radius there is σ/√mx. The vertical radius is σ/√my. Quadrupling the horizontal weight halves the horizontal radius.

With unit weights, keys at (1, 0) and (0, 2) have squared distances 1 and 4. Raise the horizontal weight to 9 and the distances become 9 and 4, so the second key gets more weight. Changing the bandwidth preserves that ordering because it multiplies both scores by the same positive factor.

Check your understanding · What happens as bandwidth grows?

Each score approaches zero and the weights approach a uniform distribution. At small bandwidth, the nearest key takes most of the weight if it is uniquely closest.
