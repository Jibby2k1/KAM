Chapter 1

Attention as a weighted average

A query asks a question. Keys say where to look. Values say what you get back.

Derive the read by hand

Imagine that two sensors report 10 and 20 degrees. The query is the location where you want an estimate, the keys are the sensor locations, and the values are their measurements. A scoring rule compares the query with each key and produces a number for each sensor.

Suppose the first score is s1 = ln 3 and the second is s2 = 0. Exponentiating gives 3 and 1. Divide both by their sum, 4, to get weights ¾ and ¼. The read is ¾ × 10 + ¼ × 20 = 12.5 degrees.

wj = exp(sj) / ∑ℓ exp(sℓ) read(q) = ∑j wj vj

Adding the same constant to both scores multiplies both exponentials by the same factor, which cancels. For two keys, only the score gap Δ = s1 − s2 matters. Divide the numerator and denominator of the first weight by exp(s1) to get w1 = 1 / (1 + exp(−Δ)).

Check your understanding · What does a tie return?

A tie sets Δ to zero, so each weight is ½ and the average is 15 degrees. If you double both scores while the first score is higher, the gap doubles and the read moves toward 10 degrees.
