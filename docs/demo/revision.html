Chapter 4

Looking up a revision

An observation describes a period. A release date says when a particular version was known.

Derive the as-of lookup

First fix the record identity and observation period. For an as-of day t, let E(t) contain the release days at or before t. The most recent eligible release is the largest member of that set.

E(t) = {d : d ≤ t}   and   d★ = max E(t)

For release days 5, 12, 23, and 30, the eligible set on day 17 is {5, 12}. Its maximum is 12, so return that record’s value of 100.9. On day 23 the inclusive cutoff adds 23 to the eligible set, so the answer becomes 101.6. An empty eligible set means no record was available.

The exact rule audits the archive labels. The learned experiment asks a decoder to recover that record from a candidate pool with the typed identity supplied.
