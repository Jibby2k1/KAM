Chapter 3

Reading a persistent memory

A combined KAM block reads the current sequence, then queries its learned support bank.

Follow one token through the two reads

Context keys and values are projections of the current and earlier tokens. Supports are learned key–value pairs shared across sequences. In a combined block, the support query is computed after the context update.

z = x + context(x) y = z + support(z)

Take a scalar token x = 1. Let its causal context read average values 0 and 4 with equal weights, so z = 1 + 2 = 3. For this example, use z directly as the support query, with unit bandwidth and support keys 0 and 4. Their scores are −9/2 and −1/2. The second key leads by 4, so its weight is 1/(1 + exp(−4)) ≈ 0.982.

Give the supports values −1 and +1. Their weighted read is 2 × 0.982 − 1 ≈ 0.964, so the second residual produces y ≈ 3.964. This scalar example isolates the order of the two reads. The block code includes normalization and learned projections. Model implementation.

Check your understanding · When do the weights tie?

The keys are equally far away when z = 2, which requires a context update of +1. Their values cancel at equal weight, leaving the output at 2.
