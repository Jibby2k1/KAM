# Temporal rank within each typed address

A clock derived from each address's own ordering improved snapshot lookup over raw time offsets on Eurostat and improved deep synthetic corrections. The gain held against assigning the same rank values to the wrong records. Dallas release-day outcomes still favored the original timestamps for dot and mixed radial. The benchmark gives the model typed per-record addresses and date fields. Inferring that metadata from prose is a separate task.

For every admitted fact record, use its workspace and entity to form a group, then rank by effective date followed by publication date within that group. Only records satisfying both query cutoff inequalities enter this feature, and exact date ties share the best rank of the group. Replace the normalized publication coordinate with minus log one plus rank, scaled by log 25, on eligible fact tokens. Ineligible and alias clocks are retained. The feature is computed before asking which address is relevant. A sham rotates the new values among the same eligible fact tokens, preserving their count and marginal distribution. All arms use the exact same 3,200 updates and 10,556,800 training tokens, model dimensions, initialization and raw input banks.

Mixed radial improved original unemployment by +76.39 percentage points [69.79, 82.32] and industry by +86.86 [81.11, 91.29]. The loss on Dallas was −13.21 [−15.85, −10.62]. Its depth-512 correction count moved from 607 to 1,260/1,536, and each seed's paired improvement was positive. The archive-shaped model continued to fail on corrections generated by a different process. The short training run, sparse calendar groups in the 2025 comparison and fixed typed representation limit the scope.
