# Temporal rank within each typed address

A clock derived from each address's own ordering improved snapshot lookup over raw time offsets on Eurostat and improved deep synthetic corrections. The gain held against assigning the same rank values to the wrong records. Dallas release-day outcomes still favored the original timestamps for dot and mixed radial. The benchmark gives the model typed per-record addresses and date fields. Inferring that metadata from prose is a separate task.

For every admitted fact record, use its workspace and entity to form a group, then rank by effective date followed by publication date within that group. Only records satisfying both query cutoff inequalities enter this feature, and exact date ties share the best rank of the group. Replace the normalized publication coordinate with minus log one plus rank, scaled by log 25, on eligible fact tokens. Ineligible and alias clocks are retained. The feature is computed before asking which address is relevant. A sham rotates the new values among the same eligible fact tokens, preserving their count and marginal distribution. All arms use the exact same 3,200 updates and 10,556,800 training tokens, model dimensions, initialization and raw input banks.

## Keep date offsets alongside rank

Adding the recency feature alongside both timestamp fields retained much of the Eurostat gain and reversed the Dallas loss in the mixed fits. In these arms, rank is encoded as one divided by one plus rank. It occupies one coordinate unused by the corresponding record type, so model width and parameter count stay fixed. A second arm adds the equivalent within-alias rank at another inactive coordinate. Each feature changes only eligible records of its matching type. The both-features sham shuffles those ranks separately by record type, preserving the marginal values and the two original clocks.

Mixed dot with fact rank improved Dallas by +4.17 points [1.32, 6.91], unemployment by +78.36 [74.05, 82.67] and industry by +91.15 [86.81, 95.25]. The seeded both-features sham reached 53.57%, 2.84% and 0.81% on these panels respectively. Adding alias rank did not consistently improve over the simpler fact-only version. Archive-shaped fits still did poorly on deep procedural corrections. On L4, the added fact feature raised median update time across the 3,200-update fit from 12.46 to 14.36 seconds in mixed dot and from 17.84 to 20.02 in mixed radial. These timers include computing the ranks in each model forward. Precomputing them as part of a real store would have a different cost.

An exact typed baseline joins by the admitted alias at the correct workspace, then picks the latest admitted payload at the resolved fact address. It abstains on conflicting top-ranked ties. It recovered all 22,560 tested archive lookups across the two depths, within each training domain and geometry. Those totals include three fits and two recodings of each query. The lookup has access to authoritative typed metadata supplied by the fixture. For an archive-shaped dot fit using both features, learned key plus exact payload improved original unemployment from 1,342 to 2,951 of 3,456 and industry from 1,703 to 3,104. Keeping the learned payload while replacing the key with the exact alias changed those counts only to 1,358 and 1,707. Explicit selection therefore fixed most of the residual failure in that fit when the learned key was right.
