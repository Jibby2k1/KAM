The river carries a pattern downstream, yet every eddy remembers the boundary that shaped it. A useful model should predict the next motion, reveal which past observations mattered, and adapt when the flow changes. Kernel memory treats previous observations as temporary supports and learned prototypes as persistent supports. The experiment is successful only when the explanation survives perturbation and the prediction remains competitive.

A sequence can be read as a language. In ordinary text, the symbols are characters or words. In a dynamical system, the symbols are delayed states. In a synthetic grammar, the symbols obey a hidden transition rule. The same architecture can be tested on all three, but each test asks a different scientific question.

Context attention retrieves an observation from the current sequence. Memory attention retrieves a reusable regime from a finite learned bank. A fast linear readout can then adapt to a new target without moving the full geometry at every step. These roles should be measured separately before they are combined.
